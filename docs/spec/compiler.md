# Compiler

## バックエンド

LLVMバックエンド。WASMはターゲットの一つ。JITも対象（LLVM ORC/MCJIT）。

## コンパイル戦略

- **ローカルDAG:** 高速インクリメンタルコンパイル。ローカルな正当性の検証。
- **グローバルDAG:** 全体最適化と完全な正当性検証。

## 所有権解析

所有権DAGをコンパイラが構築し、ライフタイムを自動推論する。ユーザーはライフタイム注釈を書かない。
