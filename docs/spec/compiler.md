# Compiler（コンパイラ）

iris のソースを実行可能な形に変換する裏方。ここでは特にバックエンド
（最終的な機械語生成）と所有権解析の方針をまとめる。

## バックエンド

LLVM を使って機械語を生成する。WASM もターゲットの一つ。将来は JIT も対象
（LLVM ORC/MCJIT）。

> 現状の注意：この環境には `llvm-config` が無く、codegen は **LLVM IR をテキストで
> 出力し `clang` に渡す**方式（詳細は `CLAUDE.md` / `docs/STATUS.md`）。JIT は将来 LLVM
> を本格導入してから。

## コンパイル戦略：2段の DAG

「速さ」と「正しさ」を両立するため、所有権 DAG を2つの粒度で扱う。

- **ローカル DAG:** 変更箇所だけを素早く検証する。高速なインクリメンタルコンパイル向け。
- **グローバル DAG:** 全体を見て最適化し、完全な正当性を検証する。

## 所有権解析

コンパイラが**所有権 DAG を構築し、ライフタイムを自動推論**する。ユーザーは
ライフタイム注釈を一切書かない（ADR-0003）。所有権モデルの全体像は `ownership.md` 参照。
