# Function（関数）

処理に名前を付けてまとめたもの。iris では戻り値の型を**後ろ**に書くのが特徴。

## 定義

```iris
fn add(a: number, b: number): number {
    return a + b
}
```

戻り値の型は `:` で後置する（引数の後ろ、本体 `{}` の前）。

## 関数型シグネチャ

「関数そのもの」も型として書ける（関数を引数や戻り値にするとき使う）。

```iris
type Func = (number, (number): number): void
```

## ラムダ（その場で作る無名関数）

`->` は「ラムダですよ」という目印で、**式**の本体を導く。
`fn` の `{}` ブロック本体とは別物（こちらは式が一つ）。

```iris
let f = (x: number): number -> x * 2
```

ブロック本体（複文）も書ける:

```iris
let g = (x: i32): i32 -> {
    let y = x * 2
    return y + 1
}
```

### 型の省略と推論

期待型が文脈から定まる位置（高階関数の引数 `f: (T): U` に渡すなど）では、引数型・戻り型を
省略でき、期待型から推論される:

```iris
v.iter().map((x) -> x * 2)   // x の型はアダプタの要求から推論
```

期待型が無い単独束縛 `let f = (x) -> ...` は推論できないため**型注釈が要る**（ADR-0013）。

### 捕獲（クロージャ）

ラムダは外側の変数を**捕獲**できる。捕獲が借用かムーブかは**所有権 DAG が捕獲ごとに推論**し、
`move` のような注釈は書かない（ADR-0003／ADR-0013）:

```iris
let k = 10
let f = (x: i32): i32 -> x * k   // k は借用で捕獲（f は即時消費されエスケープしない）
v.iter().map(f)                  // map 後も k は使える
```

クロージャがエスケープする（戻り値・フィールドへ格納）場合は、捕獲が**ムーブ**へ格上げされる
（借用のままだとダングリングになるため）。プリミティブ（数値・`bool`・`char`・`&T`）は値コピーで
捕獲される（ADR-0005 の Copy 規則）。

## イテレータアダプタ（クロージャが入った暁の最初の目標）

`Iterator<T>`（ADR-0007・`trait.md`）はクロージャが無いと高階で使えない。クロージャ導入後の
**最初の実装目標**は以下のアダプタ。これらが本実装プラン（plan 050）の受け入れ基準になる
（ここでは**意図する形**を示すのみで未実装）:

```iris
// map: 各要素に f を適用した新しいイテレータ
let doubled = v.iter().map((x) -> x * 2)

// filter: 述語 true の要素だけ残す
let evens = v.iter().filter((x) -> x % 2 == 0)

// fold: 初期値から畳み込む
let sum = v.iter().fold(0, (acc, x) -> acc + x)
```

## ジェネリクス

型を後で決める穴を `<T>` で開けておけば、色々な型で使い回せる（`type.md` 参照）。

```iris
fn map<T, U>(list: List<T>, f: (T): U): List<U> { ... }
```

## 三項演算子

短い分岐は一行で書ける（`?` が三項演算子、ADR-0002）。

```iris
let x = condition ? a : b
```
