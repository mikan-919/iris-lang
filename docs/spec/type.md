# Type（型）

型は「その値をどう扱ってよいか」を表す。iris は**名前的型付け** — 中身が同じでも
名前が違えば別の型として区別する。これは「メートルと秒を取り違える」ような
バグをコンパイル時に防ぐための選択。

## 型エイリアス

`type` で付けた名前は、ただの別名ではなく**別の型**になる（名前的型付け）。

```iris
type Meters = f64
type Seconds = f64
// 中身はどちらも f64 だが、Meters を Seconds に渡すとコンパイルエラー
```

こうすることで「長さの値を時間の関数に渡す」ような取り違えを型が止めてくれる。

## 型変換

別の型として扱いたいときは `as` で**明示的に**変換する。暗黙の変換は起きない
（気づかぬ取り違えを防ぐため）。

```iris
let m: Meters = 5.0
let f: f64 = m as f64
```

## タプル

複数の値をひとまとめにした型。後述のコレクションとは別物（要素の型がバラバラでよい）。

```iris
let t: (i32, string) = (42, "hello")
```

## コレクション

要素を並べて持つ型。長さが固定か可変かで2種類ある。

```iris
let arr: i32[] = [1, 2, 3]     // 固定長配列（Array）
let vec: Vec<i32> = [1, 2, 3]  // 動的配列（Vector）
```

配列リテラル `[...]` は**型注釈に応じて**固定長配列 `T[]` か動的配列 `Vec<T>` を作る
（型指向。注釈がなければ既定で `T[]`）。固定長配列はスタックに、`Vec<T>` はヒープ
（`malloc`）に置かれる。いずれも `for x in coll` で要素を反復できる（`control.md` 参照。
当面は要素が Copy 型のときのみ）。

> 実装状況：構築・反復は実装済み。`push` / 長さ取得 / 索引 `v[i]` / スライスは未実装。

## 文字列補間

バッククォートの中では `{...}` で値を埋め込める。

```iris
let name = "world"
let msg = `Hello, {name}!`
```

## null は存在しない

iris に null は無い。「値が無いかもしれない」状態は `Option<T>` という型で表す。
こうすると「null を見落として落ちる」事故を、型が無くしてくれる。

```iris
let x: Option<i32> = Some(42)   // 値がある
let y: Option<i32> = None       // 値がない
```

## 組み込みプリミティブ型

最初から用意されている基本の型。

| 型 | 説明 |
|----|------|
| `i8`, `i16`, `i32`, `i64` | 符号付き整数 |
| `u8`, `u16`, `u32`, `u64` | 符号なし整数 |
| `f32`, `f64` | 浮動小数点数 |
| `bool` | 真偽値 |
| `string` | 文字列 |
| `char` | 文字 |

## 自分で型を作る基本形

```iris
type Name = string                              // 別名（別の型）
type Name = enum { Str: string, Num: number }   // どれか一つ（直和）
type Name = struct { key: i32 }                 // 全部まとめて持つ（直積）
```

## 型修飾子

型の前に付けて「所有ではなく参照」を表す（詳しくは `ownership.md`）。

| 修飾子 | 意味 |
|--------|------|
| `&Type` | 不変参照（見るだけ） |
| `&mut Type` | 可変参照（書き換えOK） |

## 型合成：`+` で型を足す

iris では `+` が「型を合成する」記号（`&` は参照専用なので衝突しない、ADR-0001）。
複数のトレイトを同時に満たす型を表せる。

```iris
type Name = A + B
```

## トレイト境界

関数引数でも `+` を使い「この振る舞いを持つ型なら何でも受け取る」と書ける。

```iris
fn foo(x: Greet + Serialize): string { ... }
```

## ジェネリクス

「型を後で決める」穴を `<T>` で開けておく仕組み。同じコードを色々な型で使い回せる。

```iris
type List<T> = struct { ... }
fn map<T, U>(list: List<T>, f: (T): U): List<U> { ... }
```

型パラメータに「この振る舞いを持つこと」という条件を付ける場合は `:` を使う。

```iris
fn foo<T: Greet + Serialize>(x: T): string { ... }
```
