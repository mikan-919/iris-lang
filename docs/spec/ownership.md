# Ownership

## 基本モデル

所有権はDAG構造でコンパイラが管理する。呼び出し側は意識しない。

## ムーブセマンティクス

デフォルトは所有権のムーブ。

```
let x = MyStruct { ... }
foo(x)        // xの所有権がfooにムーブ
// ここでxは使えない
```

## コピー

明示的にコピーしたい場合は `Clone` トレイトの `.clone()` を使う。

```
let y = MyStruct { ... }
foo(y.clone()) // yはまだ使える
```

## 参照

所有権を渡さず参照だけ渡す場合は `&` / `&mut` を使う。

```
foo(&x)        // 不変参照
foo(&mut x)    // 可変参照
```

## 暗黙コピー

`Copy` トレイトを実装した型は暗黙的にコピーされる。プリミティブ型（`i32`, `f64`, `bool` など）はデフォルトで `Copy`。

```
let x: i32 = 42
foo(x)   // コピーされる、xはまだ使える
```

## 所有権DAGの制約

- 所有権グラフはDAG（有向非巡回グラフ）でなければならない——所有権のサイクルは禁止
- 非所有参照グラフにはサイクルを持てる
- 参照は生のポインタではなく、DAGの到達可能性から導出される——ヌル参照は存在しない

相互参照が必要な場合は、一方が所有し他方は非所有参照（`&`）で指す。

```
type Node = struct {
    children: Vec<Node>   // 所有
    parent: &Node         // 非所有参照（サイクル可）
}
```

## コンパイラの責務

所有権の正当性はコンパイラが所有権DAGを用いてコンパイル時に検証する。呼び出し側のコードに所有権の明示的な記述は不要。
