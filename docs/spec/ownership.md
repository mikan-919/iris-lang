# Ownership（所有権）

## まず「DAG」って何？

iris のメモリ安全性の核心は **所有権DAG** という考え方。
DAG = **有向非巡回グラフ**（Directed Acyclic Graph）。

- **有向** = 矢印に向きがある（A→B）
- **非巡回** = ぐるっと一周して戻る輪っか（サイクル）が無い

iris では「誰が誰を**所有しているか**」をこの矢印で表す。`A → B` は
「**A が B を所有している**」という意味。

```
家  →  部屋  →  家具
```

家が部屋を持ち、部屋が家具を持つ。きれいな一方通行のツリー（DAG）。
この所有権を**コンパイラが裏で管理し、呼び出し側のコードには一切書かせない**
のが iris の設計の核心（ライフタイム注釈なし、ADR-0003）。

## ムーブ：所有権の引っ越し

デフォルトは **ムーブ**。値を関数に渡すと、所有権ごと相手に**引っ越し**する。
元の変数はもう空っぽになり、使うとコンパイルエラー。

```iris
let x = MyStruct { ... }
foo(x)        // x の所有権が foo へムーブ
// ここで x を使うとエラー（もう持っていない）
```

なぜ厳しくするの？ → 2か所が同じ物を「自分のもの」と思って勝手に書き換えたり、
両方が「もう捨てていい」と二重に解放したりする**バグを、コンパイル時に潰す**ため。

## コピー：両方使いたいとき

明示的にコピーしたい場合は `Clone` トレイトの `.clone()` を使う。
コピーが作られるので、元の変数もそのまま使える。

```iris
let y = MyStruct { ... }
foo(y.clone()) // y はまだ使える
```

## 参照：所有権を渡さず「貸す」だけ

所有権を渡さず、見たり書いたりだけさせたいときは `&` / `&mut` を使う。

```iris
foo(&x)        // 不変参照（見るだけ）
foo(&mut x)    // 可変参照（書き換えもOK）
```

参照は所有の矢印（→）を**作らない**。だから貸しても所有権は手元に残る。

## 暗黙コピー：小さい値は気にしなくていい

`Copy` トレイトを実装した型は暗黙的にコピーされる。
プリミティブ型（`i32`, `f64`, `bool` など）はデフォルトで `Copy`。
ムーブされず元も使えるので、何も意識しなくてよい。

```iris
let x: i32 = 42
foo(x)   // コピーされる。x はまだ使える
```

## 所有権DAGの制約

なぜサイクルを禁止するのか。もし所有のサイクルを許すと、
「箱Aの中に箱Bが入っていて、その箱Bの中に箱Aが入っている」という**無限入れ子**に
なり、サイズが決まらずメモリ上に置けない。だから:

- **所有グラフはDAGでなければならない** — 所有のサイクルは禁止
- **非所有の参照グラフにはサイクルを持てる** — `&` は所有の矢印を作らないため
- 参照は生のポインタではなく、DAGの到達可能性から導出される — ヌル参照は存在しない

> ⚠️ ポイント：**所有（→）にはサイクル不可。でも参照（`&`）にはサイクルOK。**

親子で互いを指したい場合は、**片方が所有し、もう片方は非所有参照（`&`）** で指す。

```iris
type Node = struct {
    children: Vec<Node>   // 所有（→ を作る）
    parent: &Node         // 非所有参照（→ を作らない、サイクル可）
}
```

`parent` が上を指しても、`&` は所有の矢印を作らないので DAG は壊れない。

## コンパイラの責務：検査は3層

所有権の正当性は、コンパイラが所有権DAGを用いてコンパイル時に検証する
（実装は `src/sema/ownership/`）。3つの別々の観点で順にチェックする。

1. **型レベル：無限サイズの型を弾く**（`typegraph.rs`）
   型の定義だけを見て、前述の無限入れ子になっていないか確認。
   `&T` / `Box` / `Vec` は所有の矢印を作らないのでサイクル判定から外れる。

2. **値レベル：ムーブと寿命**（`flow.rs`）
   コードの流れを追い、ムーブ済みの変数を再び使っていないか（use-after-move）、
   その場で消える値への参照を返していないか（ダングリング）を見る。
   「この参照はどこ由来か（provenance）」を追い、**ライフタイム注釈を一切
   書かせずにコンパイラが自動推論**する（ADR-0003）。

3. **借用の競合：エイリアス規則**（`borrows.rs`）
   同じ物を同時に貸すときのルール。`&mut`（書き換え可）は**ただ1人だけ**の独占、
   `&`（見るだけ）は**何人でもOK**。読み書きの衝突を禁止する。

呼び出し側のコードに所有権の明示的な記述は不要 — これが iris の核心。
