# Control Flow（制御フロー）

プログラムの流れを分けたり繰り返したりする構文。iris は文の区切りが**改行**
（`;` は不要）で、条件式を**括弧で囲まない**のが見た目の特徴。

## 条件分岐

```iris
if condition {
    ...
} else if condition {
    ...
} else {
    ...
}
```

条件式を括弧で囲まない（`if (x)` ではなく `if x`）。

## 三項演算子

短い「どちらかを選ぶ」を一行で書ける。iris では `?` がこの三項演算子
（エラー伝播は `!`、ADR-0002）。

```iris
let x = condition ? a : b
```

## ループ

繰り返しは3種類。用途で使い分ける。

```iris
for x in list { ... }   // 何かを順番に取り出して回す
while condition { ... } // 条件が真の間まわす
loop { ... }            // 無限ループ（break で抜ける）
```

C の `for (i = 0; i < n; i++)` のような形は無い。「数えて回す」は次の整数範囲で書く。

### 整数範囲の `for`（実装済み）

`for` の対象に**整数の範囲**を書ける。「`n` 回回す」はこれ。

```iris
for i in 0..n { ... }    // 上限を含まない: 0, 1, ..., n-1
for i in 1..=n { ... }   // 上限を含む:    1, 2, ..., n
```

- 上限の含む/含まないは `match` の範囲パターンと同じ規約: `..` は排他、`..=` は包含。
- 下限・上限は任意の整数式（リテラルでも変数でもよい）。両者は同じ整数型であること。
- ループ変数 `i` は不変束縛で、毎回 1 ずつ増える。`break` / `continue` が使える。

### 一般イテレータの `for`（実装済み・ADR-0007）

対象が範囲（`..` / `..=`）でないときは、`Iterator<T>` トレイトを実装した値として
「次の要素」を1つずつ取り出して回す。

```iris
trait Iterator<T> { fn next(&mut self): Option<T> }   // std が提供

for x in iter { ... }    // iter: Iterator<T> を実装、x: T
```

- 意味としては `loop { match iter.next() { Some(x) -> { ... }, None -> break } }` 相当。
  毎回 `iter.next()` を呼び、`Some(x)` なら要素 `x`（型 `T`）を束縛して本体を実行、`None` で終了。
- `iter` は反復のあいだ可変借用される（`next(&mut self)`）。ループ変数 `x` は毎回つけ直される。
- `Iterator` を実装しない型は拒否。同じ型が複数の `Iterator`（`Iterator<i32>` と
  `Iterator<string>` 等）を実装するときの曖昧解消 `for x#T in iter`（ADR-0007）は未実装
  （当面は単一実装のみ）。

### 配列・動的配列の `for`（実装済み）

対象が固定長配列 `T[]` か動的配列 `Vec<T>` のときは、その要素を直接回す
（`Iterator` 実装より優先する組み込みの挙動）。

```iris
let a: i32[] = [1, 2, 3]
for x in a { ... }          // x: i32（各要素）

for y in [10, 20, 30] { ... }   // 配列リテラルを直接回す
```

- 意味は `0..len` のインデックスループ。要素を順に取り出してループ変数に束縛する。
- コレクションは**借用**されるだけで消費しない（回したあとも再利用できる）。ループ変数は
  毎回つけ直され、`break` / `continue` が使える。
- 当面、要素は **Copy 型のみ**（数値・`bool`・`char`・不変参照）。非 Copy 要素（struct・
  `string` 等）の反復は、要素のムーブ/借用の設計が要るため未対応。

## match：値の形で枝分かれする

`match` は「値がどんな形か」で分岐する。式なので**値を返せる**（`if` も同様）。

```iris
let result = match value {
    Ok(x) -> x
    Err(e) -> 0
}

let y = if condition { 1 } else { 0 }
```

書けるパターン：

```iris
match value {
    0 -> "zero"                      // リテラル（特定の値）
    1..10 -> "small"                 // 範囲
    Ok(x) -> x                       // enum を開けて中身を取り出す
    Some(x) if x > 0 -> "positive"   // ガード（追加の if 条件）
    _ -> "other"                     // ワイルドカード（その他全部）
}
```
