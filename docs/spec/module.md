# Module（モジュール）

コードを部品に分け、「外から使える物／内部だけの物」を仕分ける仕組み。

## 可視性：既定は非公開

何も付けないと**その場限り（非公開）**。外のコードから使わせたい物だけ `pub` を付けて
公開する。「うっかり内部実装を外に晒す」のを防ぐため、閉じているのが既定。

```iris
pub fn foo() { ... }
pub type Bar = struct { ... }
pub trait Greet { ... }
```

## インポート：他の場所の物を持ち込む

`use` で別のモジュールの物を取り込む。まるごと・一部だけ・全部、の3通り。

```iris
use std.lib              // モジュールとして取り込む（std.lib.foo の形で使う）
use std.lib { put, error }   // 指定した物だけ名前で取り込む
use std.lib.*            // 中身を全部取り込む
```
