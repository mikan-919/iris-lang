# iris-lang — Context

## Glossary

**trait**
型に振る舞いを付与する仕組み。言語の核心。`self`は第一引数として明示する。ドット記法で呼び出す。

**impl**
トレイトを型に実装するブロック。`impl <Trait> for <Type> { ... }` の形。トレイトなしの型固有メソッドも `impl <Type> { ... }` で書ける。

**let**
不変束縛。型を変えられない。再代入には宣言側に`mut`が必要。型推論あり。

**const**
コンパイル時定数。

**mut**
型修飾子。再代入・変更可能であることを宣言側で明示する。

**&Type**
不変参照。

**&mut Type**
可変参照。

**所有権DAG**
プログラム構造を有向非巡回グラフとして表現したコンパイラの内部モデル。呼び出し側には露出しない。呼び出し側は関数シグネチャに同意した前提でコンパイラが検証する。

**名前的型付け（nominal typing）**
型の同一性は名前で決まる。構造が同じでも名前が異なれば別の型。トレイト境界はトレイトの実装有無で判定する。

**Result<T, E>**
エラーを値として表現する型。`Ok(T)` または `Err(E)`。

**Option<T>**
値の不在を表す型。null は存在しない。`Some(T)` または `None`。

**!演算子**
Result/Option の早期リターン演算子。失敗時は呼び出し元に `Err` を伝播する。panic ではない。

**?演算子**
三項演算子。`cond ? a : b`。エラー伝播には使わない。
