# iris-lang — Context

## Glossary

**trait**
型に振る舞いを付与する仕組み。言語の核心。`self`は第一引数として明示する。ドット記法で呼び出す。

**impl**
トレイトを型に実装するブロック。`impl <Trait> for <Type> { ... }` の形。トレイトなしの型固有メソッドも `impl <Type> { ... }` で書ける。

**Self**
トレイト定義・impl 本体で、実装側の具象型を指すキーワード。

**関連関数**
`self` を取らない、型に属する関数（コンストラクタ `new` など）。`型名.func(...)`、境界文脈では `T.func(...)` で呼ぶ。

**Copy**
暗黙の複製を許す性質。プリミティブ（数値・bool・char・`&T`・要素が全て Copy のタプル）のみが持つ。ユーザ定義型は持たず常にムーブ（ADR-0005）。

**clone**
値を明示的に複製する操作 `x.clone()`。ムーブを避けて複製したいときに使う。

**#（曖昧解消）**
メソッドや反復の提供元が複数あるとき、呼び出し側で一意に絞る記号。`x.m#Trait<Args>()`、`for x#T in c`（ADR-0004）。

**トレイト合成（`A + B`）**
無関係なトレイトの交差。「A かつ B を満たす型」。ADR-0001 の `+`。スーパートレイトとは別物。

**スーパートレイト**
あるトレイトが別トレイトを要求する有向の関係（`trait Sub: Super`）。Sub を実装するには Super も実装が必要で、`<T: Sub>` は `T: Super` を含意する。無関係な能力を束ねる合成（`+`）とは区別する。

**コヒーレンス（スコープ・コヒーレンス）**
`use` で見えている範囲で、各 `(トレイト<型引数>, 型)` の実装が高々1つであるという不変条件。グローバルなオーファン規則は採らず、別モジュールが同じ実装を独立に持ってよいが、同一キーの実装が同時に可視になった時点でエラー。解決の提供元集合は import に相対的。

**let**
不変束縛。型を変えられない。再代入には宣言側に`mut`が必要。型推論あり。

**const**
コンパイル時定数。

**mut**
型修飾子。再代入・変更可能であることを宣言側で明示する。

**&Type**
不変参照。

**&mut Type**
可変参照。

**所有権DAG**
プログラム構造を有向非巡回グラフとして表現したコンパイラの内部モデル。呼び出し側には露出しない。呼び出し側は関数シグネチャに同意した前提でコンパイラが検証する。

**名前的型付け（nominal typing）**
型の同一性は名前で決まる。構造が同じでも名前が異なれば別の型。トレイト境界はトレイトの実装有無で判定する。

**Result<T, E>**
エラーを値として表現する型。`Ok(T)` または `Err(E)`。

**Option<T>**
値の不在を表す型。null は存在しない。`Some(T)` または `None`。

**!演算子**
Result/Option の早期リターン演算子。失敗時は呼び出し元に `Err` を伝播する。panic ではない。

**?演算子**
三項演算子。`cond ? a : b`。エラー伝播には使わない。
